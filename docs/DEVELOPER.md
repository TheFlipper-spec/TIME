# TIME — документация разработчика

## Обзор

Игра написана на **Python 3.11+ / pygame 2.6** и не требует внешних ассетов:
вся графика (тайлы, персонажи, портреты, фасады) и весь звук (SFX + фоновая
музыка) генерируются кодом. Это делает проект максимально переносимым и
простым в сборке.

## Ключевые концепции

### Время
- `GameState.minutes` — минуты текущего игрового дня (0–1439), день стартует
  в 06:00.
- `GameState.offset_min` — смещение в прошлое (0..−10080 минут, т.е. −7 дней).
- Абсолютная дата наблюдаемого мира: `src/game/time.py::world_datetime()`.
- Один игровой день = 30 реальных минут (`config.REAL_SECONDS_PER_GAME_DAY`).

### Улики и «окна времени»
`src/world/props.py::Prop` описывает интерактивный объект. Поле `window` —
список интервалов `(start, end)`, в которых улика существует. Именно так
работает перемещение во времени: надпись TIME видна только
23.11.2023 00:00 – 24.11.2023 07:59.

### Сюжетные стадии
`src/game/story.py::compute_stage()` — стадия 0..5, выводимая из найденных
улик (отпечатки → дата → TIME → EMIT → нож). Стадии открывают NPC, открытки,
дома и погоню.

### Свидетели
`src/game/witnesses.py`: каждая функция `talk_*` возвращает `Turn` —
реплику со списком `Choice` (эффект, следующий ход, условие видимости).
Запугивание использует `state.intimidation_chance` (зависит от поддержки
горожан и здоровья).

### Переводы
- `i18n.Translator.t(key)` — быстрый офлайн-перевод строк интерфейса
  (ключи в `assets/lang/ru.json`, `en.json`).
- `i18n.Translator.tr_text(text)` — перевод произвольного текста через
  Яндекс.Переводчик (legacy API-ключ или Cloud IAM + folder id), с кэшем
  на диске (`userdata/cache/translations_<lang>.json`).
- Ключи API задаются в настройках или через переменные окружения:
  `YANDEX_API_KEY`, `YANDEX_IAM_TOKEN`, `YANDEX_FOLDER_ID`.

## Как добавить новую улику

1. `src/game/clues.py` — добавить `Clue(...)` (id, RU/EN названия, описание,
   награда, вес для новостей).
2. `src/world/props.py` — добавить `Prop` с `clue_id` и `window` (когда
   улика существует).
3. При необходимости — реплика свидетеля в `witnesses.py` и ветка стадии
   в `story.compute_stage()`.

## Тестирование

```bash
python tests/smoke.py
```

Запускается headless (dummy SDL). Покрыто: часы/дни/дедлайн, экономика,
переводы, сохранения, диалоги, стадии сюжета, полный проход сюжета,
новости/брифинги, меню, магазин/банк, расписания NPC, реальный цикл окна
с событиями, сборка Windows-дистрибутива (статические проверки PE/DLL).

## Замечания по производительности

- Игра рендерится в фиксированном разрешении 1280×720 и масштабируется
  на окно (`App._present`), поэтому работает на любом разрешении.
- Тайлы и спрайты кэшируются в `SpriteBank`; партиклы лёгкие.
- В целевом билде ~4–5 мс на кадр (без VSync).
