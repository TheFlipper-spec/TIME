# История изменений

## 1.0.0 — 2026-08-16

Первая релизная версия.

### Игра
- Заставка с анимацией «FL1PPER» и главное меню (новая игра / загрузка /
  настройки / выход) с переключателем языка.
- Интро-карточки сюжета без спойлеров.
- Город: дом Майка, магазин «У Бориса», банк, полицейский участок,
  дом жертвы, дом EMIT, склад, парк, остановка, выезд из города.
- Механика **перемещения во времени** (`Q`): шаг ±1 час / ±1 день,
  слайдер, дата в центре, «вернуться в настоящее»; улики, предметы
  и люди меняются в зависимости от даты.
- Полный сюжет: отпечатки Ника → 23.11.2023 → надпись кровью TIME →
  записка «наоборот» → досье EMIT → кровавый нож → погоня → финал.
- 7 игровых дней, день = 24 часа = 30 реальных минут.
- Усталость (замедление, обморок на 16 часов), кровать, болезнь
  (лекарство $150), голод, холодильник.
- Экономика: награды за улики на следующий день, коммуналка $30/день
  (кроме 1-го дня), кредиты банка +25% за 3 дня, потеря квартиры.
- Вечерние новости с ведущей, поддержка горожан.
- Свидетели с характерами: свободные, с заданиями (Ник, Борис и кот
  Рыжик), запугивание как альтернатива.
- Открытки убийцы по мере продвижения расследования.
- Блокнот (J): улики, свидетели, открытки, дело, заметки.
- Обучение дружелюбными подсказками, без спойлеров.

### Технически
- 40+ файлов, ~8000 строк; процедурная графика и звук без внешних ассетов.
- Локализация: RU/EN офлайн; остальные языки — автоперевод
  Яндекс.Переводчиком с дисковым кэшем.
- Сохранения: 6 слотов + автосохранение в начале дня (JSON).
- Настройки: разрешение (по умолчанию системное), полный экран, громкость.
- Автотесты: `tests/smoke.py` (100+ проверок, headless).
- Windows-сборка: `tools/build_windows.py` (портативная, CPython 3.13
  embeddable + pygame) и `build_windows.bat` (PyInstaller onefile).
