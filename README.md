# TIME

**Детектив, в котором время — оружие.**

Игра **FL1PPER**. Python + Pygame, полностью самодостаточная: графика и звук генерируются кодом, файлов с ассетами не нужно.

---

## Как запустить

Нужен **Python 3.9+** и библиотека **pygame**:

```bash
pip install -r requirements.txt
python main.py
```

Или просто:

- **Windows** — `run.bat`
- **Linux / macOS** — `run.sh`

## Управление

| Клавиша | Действие |
|---|---|
| `W A S D` / стрелки | движение |
| `Shift` | бег (быстрее утомляет) |
| `E` | осмотреть / поговорить / войти |
| `Q` | **перемещение во времени** |
| `J` / `Tab` | блокнот |
| `Esc` | пауза / закрыть окно |
| Мышь | меню, выборы в диалогах |

## Сюжет

Ночь с 22 на 23 ноября 2023 года. В собственном доме убит Виктор Соколов.
Полиция нашла только одно: на кухне пропал нож. Вы — Майк, частный детектив
с редким даром: вы умеете возвращаться во времени в те же самые места.

Город дал вам **семь дней**. Если дело не будет раскрыто — его закроют навсегда.

## Механики

- **Перемещение во времени** (`Q`): улики, предметы и люди меняются в зависимости
  от даты. Что-то можно найти только в прошлом.
- **24 часа = 30 реальных минут.** Часы идут всегда; город живёт по расписанию.
- **Усталость** — бег и бодрствование утомляют. Устали — замедляетесь;
  вырубились — проспали 16 часов. Кровать дома снимает усталость.
- **Болезнь** — частые переутомления не проходят даром. Лекарство — $150 в магазине.
  Без лечения Майк не доживёт до конца дела.
- **Голод** — еда в магазине («У Бориса»). Дома есть холодильник (раз в день).
- **Деньги** — за каждую найденную улику на следующий день платят; чем ценнее
  улика, тем больше награда. Каждый день (кроме первого) — $30 за коммунальные
  услуги. В банке можно взять кредит: через 3 дня вернуть на 25% больше,
  иначе квартиру отберут.
- **Новости** — каждый вечер ведущая Анна Светлова оценивает расследование.
  Поддержка горожан влияет на то, охотно ли свидетели помогают.
- **Свидетели** — у каждого свой характер. Кто-то расскажет просто так,
  кому-то нужна услуга (например, «отмыть» от обвинений мелкого воришку),
  а от кого-то информацию можно попытаться **выбить силой** — но это риск.
- **Открытки** — чем ближе вы к разгадке, тем смелее убийца. Он подсылает
  открытки с подсказками, о которых ещё надо додуматься.

## Сохранения

Прогресс хранится в `userdata/saves/` (JSON). Доступны слоты 1–6 + автосохранение
в начале каждого дня. Сохраниться можно в любой момент через паузу (`Esc`).

## Настройки

Разрешение (по умолчанию — системное), полный экран, язык, громкость.

## Языки

- **Русский** и **English** — полные офлайн-переводы.
- Остальные языки игра переводит **сама через Яндекс.Переводчик**: вставьте
  бесплатный ключ API в «Настройки → Автоперевод (Яндекс)» (или задайте
  переменные окружения `YANDEX_API_KEY` / `YANDEX_IAM_TOKEN` + `YANDEX_FOLDER_ID`).
  Переводы кэшируются, повторно не запрашиваются.

## Структура проекта

```
main.py                  — точка входа
src/
  core/                  — окно, цикл, сцены, камера, ввод
  scenes/                — заставка, меню, геймплей, диалоги, новости…
  game/                  — время, улики, экономика, свидетели, сюжет
  world/                 — город, здания, интерьеры, NPC, улики-пропсы
  render/                — процедурная графика, шрифты, UI, эффекты
  audio.py               — процедурный звук и музыка
  i18n.py                — переводы (офлайн + Яндекс)
  saves.py               — сохранения
  settings.py            — настройки игрока
assets/lang/             — словари переводов (ru, en)
tests/smoke.py           — автотесты всей игры (headless)
```

Запуск тестов:

```bash
python tests/smoke.py
```
